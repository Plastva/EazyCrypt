🔐 EazyCrypt

🛡️ Securitatea aplicației

Aplicația EazyCrypt utilizează tehnologii moderne pentru a asigura protecția datelor utilizatorilor.

🔐 Autentificare securizată

  • Autentificare prin Firebase Authentication
  • Verificare cont prin email
  • Protecție împotriva accesului neautorizat

🔑 Criptare AES

  • Algoritm AES-GCM (Advanced Encryption Standard)
  • Criptare realizată direct în browser
  • Parola NU este stocată pe server

🧠 Protecția datelor

  • Datele nu sunt salvate pe server
  • Procesarea se face local (client-side)
  • Fișierele criptate sunt descărcate doar de utilizator

⚠️ Recomandări

  • Folosește parole puternice
  • Nu pierde parola — datele nu pot fi recuperate
  • Nu distribui fișiere criptate fără parola corectă
