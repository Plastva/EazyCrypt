EazyCrypt

Securitatea aplicatiei

Aplicatia EazyCrypt utilizeaza tehnologii moderne pentru a asigura protectia datelor utilizatorilor.

Autentificare securizata

  • Autentificare prin Firebase Authentication
  • Verificare cont prin email
  • Protectie impotriva accesului neautorizat

AES-GCM

AES-GCM este un algoritm modern care cripteaza datele si verifica integritatea lor la decriptare.

PBKDF2

PBKDF2 transforma parola utilizatorului intr-o cheie criptografica prin multe iteratii SHA-256.

Salt

Saltul este o valoare aleatorie folosita la derivarea cheii, astfel incat aceeasi parola sa produca rezultate diferite.

IV

IV-ul este un vector de initializare aleatoriu necesar pentru ca fiecare criptare AES-GCM sa fie unica.

Criptare client-side

Criptarea si decriptarea au loc in browser, iar fisierul original nu este trimis catre un server.

Parola nu este stocata

Parola este folosita doar local pentru derivarea cheii si nu este salvata pe server.

Recomandari

  • Foloseste parole puternice
  • Nu pierde parola - datele nu pot fi recuperate
  • Nu distribui fisiere criptate fara parola corecta
